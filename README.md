# Carta de cumpleaños interactiva

1. Abre `index.html` en tu navegador.
2. Cambia el nombre y la fecha en el archivo si quieres personalizarlo más.
3. Usa el botón "Cambiar foto" para subir una imagen.
4. Haz clic en el corazón para entrar y en el sobre para abrir la carta.

Este proyecto está listo para servir como una página web estática.
